# ppt-master sidecar service

FastAPI wrapper around the [ppt-master](https://github.com/hugohe3/ppt-master) skill
(MIT, Copyright (c) 2025-2026 Hugo He), pinned to release `v5.0.0`.

Pixora's Node backend owns the LLM work; this service owns everything that must run
in Python: project scaffolding, source conversion, SVG quality validation and the
deterministic SVG -> native PPTX compilation.

## Why a separate service

`ppt-master` is a Python agent skill, not a library. Its export half is fully
headless, but it requires Python 3.10+, `python-pptx`, `skia-pathops` and
`uharfbuzz`. The Pixora API runs on a Node runtime, so the Python half lives in its
own container.

## Hard constraint: the skill is immutable

`skills/ppt-master/scripts/attribution_guard.py` AST-checks 13 gate files, SHA-256
checks `LICENSE`, and regex-checks `SKILL.md` frontmatter. Any modification makes
every entry script exit with code 78. The image therefore installs the official
release archive unchanged and mounts it read-only. Never edit anything under
`PPT_MASTER_SKILL_DIR`.

## Endpoints

All endpoints except `/health` require the `X-Pixora-Service-Key` header.

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/health` | Liveness plus attribution-guard self-check |
| `GET` | `/fonts` | Font families actually installed in the container |
| `GET` | `/catalog` | brand / style / layout / deck template indexes |
| `GET` | `/catalog/{kind}/{template_id}/spec` | Raw `design_spec.md` for prompt injection |
| `POST` | `/sources/convert` | Upload a document, get Markdown back |
| `POST` | `/decks` | Create a quick-generate project |
| `PUT` | `/decks/{deck_id}/svg/{name}` | Write one authored slide SVG |
| `PUT` | `/decks/{deck_id}/images/{name}` | Write one image into `images/` |
| `POST` | `/decks/{deck_id}/check` | Run the SVG quality gate, return structured errors |
| `POST` | `/decks/{deck_id}/export` | Compile and return the `.pptx` |
| `DELETE` | `/decks/{deck_id}` | Delete the working directory |

## Environment variables

| Name | Default | Purpose |
| --- | --- | --- |
| `PPT_MASTER_SERVICE_KEY` | required | Shared secret for every authenticated route |
| `PPT_MASTER_SKILL_DIR` | `/opt/ppt-master/skills/ppt-master` | Vendored skill location |
| `PPT_MASTER_WORKDIR` | `/var/tmp/ppt-master` | Deck working directories |
| `PPT_MASTER_COMMAND_TIMEOUT` | `900` | Per-subprocess timeout in seconds |
| `PORT` | `8080` | Listen port |

No model credentials belong here. Images are generated by the Node backend under
the tenant model policy and uploaded through `PUT /decks/{deck_id}/images/{name}`.

## Local development

```powershell
docker build -t pixora-ppt-master services/ppt-master-service
docker run --rm -p 8080:8080 -e PPT_MASTER_SERVICE_KEY=dev-secret pixora-ppt-master
curl.exe http://localhost:8080/health
```

## Smoke test

`smoke.py` reproduces the upstream zero-AI pipeline check: it writes a minimal SVG
roster, runs the quality checker, exports a deck and asserts the resulting package
contains real slide XML.

```powershell
docker run --rm -e PPT_MASTER_SERVICE_KEY=dev-secret pixora-ppt-master python smoke.py
```
